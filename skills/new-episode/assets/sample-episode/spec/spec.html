The context window is a budget

Each Slide shows its words as tabs above its Options, which are tabs too: open each, pick one, and dictate a note where it should change. Save at the bottom when done.

Brief

Format

Short, about eight minutes: two Sections of two Slides each, recorded in one take.

Audience

Developers who use a coding agent every day and have watched it forget an instruction halfway through a long session.

Style

Editorial: developers read code-heavy Slides fast, and sober, self-explanatory ones keep their attention on the one idea.

Learning goal

The viewer can explain why an agent forgets in a long session and decide what to put into its context and what to leave out.

Actionables

  • Start a new session when the task changes, instead of steering an old one.
  • Move standing instructions into a file the agent reads at start, and delete them from the chat.
  • Before pasting a log or a file, cut it to the lines the task needs.

Hook

You told the agent once, clearly, and an hour later it does the opposite. It did not ignore you. It ran out of room.

Red thread

Every token costs attention, so the viewer's job is budgeting: what earns a place in the window, and what is waste that crowds out the instruction that mattered.

Analogy

A household budget: rent is the system prompt, groceries are the task, and every pasted log is an impulse buy that leaves less for the rent.

Constraints

  • Every number on a Slide comes from a research file; the afternoon session is told, never measured.
  • No model or product names: the Episode outlives them.

Research questions

  • Why does a language model's recall of an instruction degrade with its position in a long context?
  • Why does starting a fresh session restore instruction following that a long session lost?

Style

Editorial: developers read code-heavy Slides fast, and sober, self-explanatory ones keep their attention on the one idea.

Visual language

The window is always a horizontal bar, filled left to right with message blocks. No motion: the bar's fill carries the point. The accent marks the instruction block wherever it sits.

Every token is spent attention

the window fills and every message takes a share, so the Hook's instruction had less left

Visual idea

master: basic-page · motion: none

A window drawn as a bar that fills with blocks, one per message, while the share left for the newest answer shrinks.

Voice script

  1. Whole window, every turn — A model reads its whole window on every turn. Each line you add takes a share of the attention the next answer gets.
  2. Not seen, but how much — So the question is never whether the agent saw your instruction. It is how much attention was left for it.

Speaker notes

  1. Attention sums to one — a softmax normalises each token's attention weights over the window, so every token added dilutes the share of the rest [1].
    • [1] Attention Is All You Need — https://arxiv.org/abs/1706.03762
  2. The window has a size — a model's context window is a fixed maximum number of tokens it can reference at once [2].
    • [2] Context windows — https://docs.claude.com/en/docs/build-with-claude/context-windows
    • target: the bar in the visual

The middle goes quiet first

the afternoon session's instruction now sits in the middle, where recall drops

Visual idea

master: three-column · motion: none

Voice script

  1. Start and end, not the middle — Models recall the start and the end of a long window better than the middle. Your instruction from an hour ago now sits in the middle.

Speaker notes

  1. A longer window does not help — extended-context models show the same drop in the middle; size alone does not make it reliable [1].
    • [1] Lost in the Middle — https://arxiv.org/abs/2307.03172

Start fresh when the task changes

a fresh session spends the whole budget on the work at hand

Visual idea

master: basic-page · motion: none

Voice script

  1. Rent on the past — A new task in an old session pays rent on everything that came before. A fresh session spends the whole budget on the work in front of you.

Speaker notes

  1. The start is weighted most — attention carries a built-in bias toward the start of the input, so a fresh session puts the new task where it counts most [1].
    • [1] Found in the Middle — https://arxiv.org/abs/2406.16008

Cut what you paste

the afternoon ends with ten lines pasted instead of a full log

Visual idea

master: basic-page · motion: none

Voice script

  1. Impulse buy — A full log is an impulse buy. Paste the ten lines that matter, and keep standing instructions in a file the agent reads at start.

Speaker notes

  1. Why the file works — text read at the start of a session sits where recall is strongest, so standing instructions there survive a long session [1].
    • [1] Lost in the Middle — https://arxiv.org/abs/2307.03172
