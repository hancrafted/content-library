# Prompt checks

Apply every row to every do and review prompt of a Workflow, rendered with `render-prompt.ts`. The evidence column points to the research question that holds the finding; read it before changing or arguing a check. A check whose research stops supporting it is cut, not softened. Lessons from our own runs, which are about chat products rather than models, live in _Prompts that survive the free tier_ in `docs/features/agentic-workflow.md`.

## Research jobs

| Check                                                                                           | How to test it                                                                                                                                                                        | Evidence                                                                                         |
| ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Every claim carries the URL of its own source, and the prompt promises checkability, not truth. | The template has a source per price, rating or fact; the wording says "so you can check it", never "so it is correct". The stand-in run's `check:sources --links` finds no dead link. | [LLM-0016](../../../docs/llm-wiki/research/LLM/LLM-0016__source-per-claim-checkable/research.md) |

## Review jobs

| Check                                                                 | How to test it                                                                                                                                                                                                              | Evidence                                                                                               |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| The review runs in a new chat that sees only the result and the goal. | The review prompt holds the result and the done lines as slots, no history; it sits at a gate, not after every job. The gain is thin, so a review earns its extra chat only where an error would carry into the next stage. | [LLM-0017](../../../docs/llm-wiki/research/LLM/LLM-0017__fresh-chat-review-catches-errors/research.md) |

## Prompt text

Write each section with `/writing-for-agents`: the positive target behaviour, one meaning in one place, no sentence the model obeys by default. That skill is house style, not evidence.
