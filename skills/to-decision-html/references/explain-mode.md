# Explain mode

An `explain` page teaches decisions someone else already made, such as a ticket's, and leaves them settled.

- Each item gives its decision a visual and at least one concrete example: a scenario, a before and after, or a worked case.
- A settled decision has no recommendation, door or effort left to weigh, so an item answers only the confidence bar's questions without a `(decide)` mark.
- Responses are the reader's questions, so the page carries no Options, response inputs or Next action. Reviewer tools stay: a theme select or show/hide toggle sits outside the items, or names what it changes with `aria-controls`.
- The reflection block draws on general non-functional lenses: systems and critical thinking, information architecture, security for engineers, and UX for audience-facing work. Choose the lenses that fit the audience.
- A **Questions?** block holds a labelled comment field with Copy as prompt and Save from the [feedback contract](feedback-contract.md). It carries the reader's questions to the agent or the decisions' author.
