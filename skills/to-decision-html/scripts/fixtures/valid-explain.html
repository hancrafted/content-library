1. Five failed logins lock an account for fifteen minutes

What changes for you: a sixth attempt inside the window is refused before the password is checked. Rung: diagram, enough because the decision is about the order of checks, not the screen.

Evidence: 1,800 failed logins from one address in an hour (incident report, 2026-09-14).

Example: Ana mistypes her password five times at 09:00. At 09:05 her sixth try is refused; at 09:15 she can try again.

2. A locked-out user sees when they can try again

What changes for you: the generic error gains a retry time. Rung: mock, enough because the wording is the decision.

Agent proposal: the message names the time, not a countdown. Unknown: screen-reader wording.
