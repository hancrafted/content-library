# Hands-on progress ticket

## Task

Create one standalone HTML page that explains the decisions in `issue.md` to an engineer who did not write it, so they understand them faster than from the text, and can send their questions back.

## Input

Use only the attached `issue.md`, a closed GitHub issue frozen as Markdown. Its decisions are settled.

## Limits

The issues, pull request and ADR it references are not attached, and the repository is not available: treat what they would say as unknown. Explain what the issue decides and mark everything beyond it as unknown or as your proposal.
