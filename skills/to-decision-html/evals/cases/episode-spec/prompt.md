# Slide Options review

## Task

Present the Slides in `decisions.md` and their Options as one standalone HTML review page, at the design size and render presets in the calibration, so I can pick an Option per Slide, comment on it and choose the next action.

## Input

Use only the attached files:

- `decisions.md`: the Brief, then the Title slide and four Slides, each with its purpose, its words and two or three Options. Each Option carries its mock as HTML.
- `visual-language.html` and `episode-page.html`: the Episode's Visual language and Episode page, as HTML fragments.
- `design.css`: the compiled design tokens and type roles the mocks use. Inline it so the page stands alone.

## Limits

Show each mock as given; do not redraw or reword it. The page asks for my pick on every Slide; building the Slides comes after my approval.
