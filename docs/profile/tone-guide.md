# Han's tone

How a Voice script sounds in Han's voice. The listener hears it once and sees nothing. Examples show the move. Write fresh lines from the Episode's own material.

## Principles

1. **Don't make me think.** Do the connecting work for the listener: say why it matters to them, so the link is made for them.
   - Example: "And like that colleague, an agent needs the right information at the right time."
   - Not this: a bare problem statement the listener has to relate to their own life.

2. **Calibrated candour.** Say how sure you are. State proven facts plainly. Mark anything without research or proof with "this is my hypothesis".
   - Example: "How much an agent can be trusted with is not settled. That's an open problem."
   - Not this: hedging every sentence, or a guess stated as fact.

3. **Hand over the verdict.** Close an argument with a question the listener answers for themselves.
   - Example: "If you own this process, would you trust that person?"
   - Not this: "Obviously, you shouldn't trust it."

4. **Sell from the listener's side.** Make the offer in terms of what the listener gains. Self-promotion at the start makes everything after it sound like a sales pitch.
   - Example: "If we all agree to use the same vocabulary, the checker gets written once. And it works everywhere."
   - Not this: "My tool is the best solution for this."

5. **Passionate professor.** Speak as a teacher who loves passing knowledge to capable peers. State the stakes plainly and calmly.
   - Example: "Right now we are living a bit on borrowed time."
   - Not this: "This will revolutionise everything."

6. **Reasoning-length sentences.** Keep Han's natural length, and let a sentence run long when it explains a concept or connects the dots. Join it with connectives that carry the logic ("because", "so", "which means"), so each long sentence is one line of reasoning. Mark a beat with "(pause)".
   - Example: "Writing was the brake, because you could only produce documentation as fast as someone could write it, and that held the whole thing in check."
   - Not this: clauses strung on "and", none following from the one before.

7. **Antithesis.** Put two halves side by side in the same shape, so the contrast does the arguing.
   - Example: "AI made it nearly free. Checking whether it's still true got more expensive."
   - Not this: "Writing is cheaper but checking is harder, which is a problem."

## Optional moves

8. **Refrain**, at most one per Episode: a line that returns at the end of several Sections to land the thesis.
   - Example: "…the part that was always yours."
9. **Show the method**, in an Episode that teaches a method: point at the method while you use it.
   - Example: "Notice I'm making a claim right now. You have no way to prove it."

## Guardrails

10. **Every word carries meaning.** Strike spoken filler such as "right?", "again", "basically" and "so yeah".
11. **Plain, specific words.** Use the concrete term in place of buzzwords such as "game-changer", "unlock" or "supercharge".
