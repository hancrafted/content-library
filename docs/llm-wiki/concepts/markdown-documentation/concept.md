# Markdown documentation

Markdown documentation is writing and maintaining plain-text documents so that people and AI read the same single source of truth.

Plain text in Markdown is easy for a person to edit and for a model to read, so one document can serve both without a copy for each. Keeping it current is the work. What an AI does with those documents once it reads them is context engineering.
