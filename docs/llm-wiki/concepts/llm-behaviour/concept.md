# LLM behaviour

LLM behaviour is how a large language model behaves as a system, whatever it is fed: it can answer the same prompt differently each time, and it sounds confident even when a prompt is vague.

These traits belong to the model, not to the user, so they hold across tools and tasks. Knowing them tells you what to expect and what to check. What you should feed the model to get better results is context engineering.
