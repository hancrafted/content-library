# Context engineering

Context engineering is deciding what an AI is given to work from: what sits in its context window, the brief it starts from, what it remembers between chats and what it knows about your organisation.

It is the input side of working with AI. A model can only use what reaches it, and the window it reads has a limit, so choosing, ordering and refreshing that material decides much of the result. How the model then behaves with it is LLM behaviour; handing it a whole task is agentic AI.
